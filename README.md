# MonitorCowboy

Control your monitors over DDC/CI straight from [Flow Launcher](https://www.flowlauncher.com/) — switch the input source and adjust speaker volume without reaching for the OSD buttons.

**Status:** under active development. First release coming soon.

## Planned v1 features

- `mc` lists every DDC/CI-capable monitor with its current input and volume
- Drill into a monitor to switch its input source (HDMI / DisplayPort / USB-C / ...)
- Set or step speaker volume
- Everything served from a warm cache — no waiting on slow DDC/CI round-trips while you type
